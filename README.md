## `> /models`

I quantize and port open models so they run on AMD GPUs, Strix Halo and the Ryzen AI NPU. Every file I publish is
measured against the original BF16 model, and the numbers are on each model card.

- **[ROCmFPX](https://github.com/HarshaVardhan3002/ROCmFPX)**: a llama.cpp fork with low-bit weight types for AMD GPUs
  (Vulkan and HIP). All my GGUF quants are made with it.
- **[zunzun](https://github.com/HarshaVardhan3002/zunzun)**: an inference engine for very large mixture-of-experts
  models on machines with limited RAM.
- **Speech on the NPU**: [Phonon-2](https://huggingface.co/Harsha001/Phonon-2-XDNA2) and
  [Underdog Bark 3.0](https://huggingface.co/Harsha001/Underdog-Bark-3.0-XDNA2) ported to the AMD XDNA2 NPU with
  Windows ML.
- **[Intrinsic_Model_harness](https://github.com/HarshaVardhan3002/Intrinsic_Model_harness)**: serving one MoE model
  with a built-in harness that steers it during inference.

## `> /apps`

- **[Nimbus](https://github.com/HarshaVardhan3002/Nimbus_revanced)**: an always-on desktop assistant for small
  automation tasks.
- **[nimbus HUD](https://github.com/HarshaVardhan3002/nimbus)**: an agent overlay for Windows and Mac that answers
  questions about anything on screen.
- **[Daimon](https://github.com/HarshaVardhan3002/Daimon)**: an LLM chat app for phones.
- **[SCIONfit](https://github.com/HarshaVardhan3002/SCIONfit)**: tests AI models in a near-deployment setup with
  agentic workflows.
- **[HCR-EV](https://github.com/HarshaVardhan3002/HCR-EV)**: edge AI for real-time electric vehicle powertrain
  optimization.
- **[MARL_path_selector](https://github.com/HarshaVardhan3002/MARL_path_selector)**: multi-agent reinforcement
  learning for network path selection on SCION end hosts.
- **[Namma Office](https://harshavardhan3002.github.io/namma-office-downloads/)**: spreadsheet, writer and PDF apps
  with Kannada typing.
